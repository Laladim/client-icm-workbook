# Reusable client system

Purpose: a public ICM workbook for installing and onboarding private digital-marketing client workspaces. One client engagement is the repeating unit. The result is an umbrella of seven areas plus an ordered onboarding record, not one giant content pipeline.

| Job | Read | Output and gate |
|---|---|---|
| Install and interview a new client | SETUP.md | private interview answers and exact client brief; human brief approval |
| Fill the workbook manually | NEW-CLIENT-DISCOVERY.md | labeled answers and source references |
| Understand what goes in each folder | FILE-BUILD-MAP.csv and docs/FOLDER-GUIDE.md | one canonical answer destination |
| Continue a private client | that workspace's CONTEXT.md and tool status | first incomplete onboarding gate or named operational owner |
| Adapt a client to existing workflows | docs/OWNER-BINDINGS.md | explicit owner entry, inputs, outputs and authority |
| Prepare live integration | deploy/HANDOFF.md | separate supervised pilot; no inherited publication permission |
| Change the reusable template | scripts/verify-template.py and tests | public-source audit and isolated real setup replay |

Factory files stay in this repository. Client facts, evidence, outputs, decisions, credentials and performance stay outside it. Examples are fictional, and fixture approvals never approve a real client.
