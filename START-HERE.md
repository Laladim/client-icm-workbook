# Start a private client workspace

1. Open this repository in Claude Code or Codex.
2. Say: `Read SETUP.md and guide me through installing and onboarding a private client ICM workspace.`
3. Choose a path for a new private folder outside the template repository. The installer creates it. The agent asks up to three missing questions at a time.
4. Review and approve the exact client brief, then review and accept the generated workspace.
5. Start at that client's CONTEXT.md for future work. Use its actual owners and source checks.

Prefer to work manually? Use NEW-CLIENT-DISCOVERY.md, docs/FOLDER-GUIDE.md and FILE-BUILD-MAP.csv. You can record unknowns and collect missing evidence later. Keep identity, scope, reviewer, authority and privacy decisions explicit before calling setup accepted.

You need Python 3.10 or later to use the local installer/checker, and a way to obtain this repository (Git clone, a GitHub template copy, or Download ZIP). The workbook does not require an API subscription, model API key or platform connector. Your chosen assistant still needs its own normal account/access.
