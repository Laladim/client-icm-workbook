# Bind the actual owner

For each client concern or channel, record the owning person/workflow, a real entry file or manual procedure, exact input and output homes, evidence freshness rule, review gate, and authority for external actions. Inspect a path or tool before claiming it works. A tool inventory is not an integration.

An existing blog, newsletter, CRM, analytics, publishing, agency or company-record workflow stays canonical. Link it from the relevant client CONTEXT.md; do not copy its stages or override its gates. If a capability is unavailable, record a manual route or a gap and the next source to check. Do not invent an adapter, API, account or expert.

Publication, ad spending, outreach, customer data, legal review, production websites and credentials each retain their own authority. An onboarding brief can describe desired delegation, but this workbook remains local-only. A supervised live pilot must name the exact task, tool permission, target, dry run/readback, recovery, human reviewer and stop rule. Routine operation requires its own accepted client contract.
