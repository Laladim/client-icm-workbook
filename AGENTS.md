# Client ICM Workbook entry

New client: read SETUP.md. Use the canonical question bank, inspect supplied material first, then ask up to three missing questions at a time. Keep supplied facts, researched evidence, interpretations and human decisions separate. Never copy an example's facts or authority into a real client.

Install one private client workspace outside this public template repository. Never modify an existing client workspace as an installation side effect. The installer copies only the portable client template, question bank and local workbook tool. It changes no global settings, hooks, accounts or credentials.

Stop for the named human to approve the exact client brief before generating the seven-area workspace. Stop again for human acceptance of the exact generated workspace before calling it accepted. Explicit approval is bound to the displayed hash. Do not approve on the human's behalf. Preparing this reusable workbook does not require anyone to complete a real client interview.

Every installation begins local-only: no sending, posting, publishing, ad spending, account changes or background jobs. Platform pilots and routine production require their own client-specific authority, actual tool scope, checks and handoffs. Existing workflows remain authoritative when bound.

Continue an installed client from that workspace's AGENTS.md and CONTEXT.md, using scripts/workbook.py status to derive progress from files. The public repository contains no client records. Never push real client data here.
